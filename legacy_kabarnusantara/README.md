# KabarNusantara - Portal Berita Indonesia Terkini

Website portal berita Indonesia modern, responsif, dan siap pakai langsung di peramban (browser) tanpa instalasi dependensi rumit.

## 🚀 Fitur Utama

1. **Desain Modern & Responsif**:
   - Tampilan editorial bersih dan rapi menggunakan **Tailwind CSS**, font *Plus Jakarta Sans* & *Merriweather*.
   - Nyaman diakses lewat smartphone, tablet, maupun desktop.
2. **Kategori Lengkap**:
   - Nasional & Politik
   - Ekonomi & Bisnis
   - Teknologi & AI
   - Olahraga (Sepak bola & Timnas)
   - Otomotif
   - Hiburan & Kebudayaan
   - Edukasi
3. **Pencarian Real-Time (Live Search)**:
   - Pencarian instan berdasarkan judul, ringkasan, penulis, atau kata kunci topik.
4. **Pembaca Berita Interaktif (Modal Reader)**:
   - Tampilan baca fokus tanpa gangguan.
   - **Text-to-Speech (Fitur Audio Berita)**: Dengarkan artikel dibacakan otomatis dalam Bahasa Indonesia menggunakan Web Speech API.
   - Bagikan berita (Web Share API & Salin tautan).
5. **Simpan Berita (Bookmark / Baca Nanti)**:
   - Fitur simpan artikel favorit berbasis `localStorage` lokal tanpa perlu login.
6. **Sekilas Info (Breaking News Ticker)**:
   - Running text berita penting dan genting di bagian atas halaman.
7. **Mode Gelap / Terang (Dark & Light Mode)**:
   - Tombol toggle mode gelap/terang otomatis tersimpan di preferensi browser.
8. **Live Jam & Tanggal WIB**:
   - Penunjuk waktu dan tanggal standar waktu Indonesia Barat secara aktual.

---

## 💻 Cara Menjalankan

Cukup klik dua kali berkas **`index.html`** atau buka berkas tersebut menggunakan peramban favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).

Berkas proyek:
- `index.html` — Struktur halaman web & tata letak UI
- `style.css` — Styling kustom, animasi marquee, dan estetika tipografi
- `app.js` — Logika data berita, live search, filter kategori, bookmark, dan text-to-speech
